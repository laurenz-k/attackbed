Role Name
=========

Ansible Role that installs an configures [docker-ce](https://www.docker.com/)

Requirements
------------

Any Debian or Ubuntu should do.

Role Variables
--------------

There are no role variables to configure

Example Playbook
----------------

```yaml
- hosts: localhost
  roles:
    - dockerce
```
